# Simple Interest Calculator

This project is a simple Bash script that calculates simple interest based on user input.

## Description
The script prompts the user to enter:
- Principal amount
- Rate of interest
- Time period

It then calculates the simple interest using the formula:

Simple Interest = (Principal * Rate * Time) / 100

## How to run
```bash
bash simple-interest.sh
```

## Output
The script displays the calculated simple interest to the user.
